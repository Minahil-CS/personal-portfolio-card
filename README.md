
# Personal Portfolio Card

**Advanced Session – Task 1**  
**SpireX Foundation**

## About the Project

A responsive personal portfolio card developed using HTML, CSS, and JavaScript. It showcases my academic background, technical skills, featured projects, and contact information in a modern and interactive design.

## Features

- Responsive layout for desktop, tablet, and mobile
- Dark and light theme switcher
- Interactive project filters
- Project cards with hover animations
- Contact and social profile links
- Accessible buttons and keyboard navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
